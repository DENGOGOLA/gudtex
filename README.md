GudText Engine Ultra v5.1
GudText — это мой собственный игровой движок на базе текстовых команд.

Особенности:
Простой синтаксис: Команды вроде импорт, кнопка, переместить.

Мультимедиа: Поддержка картинок (через iframe) и музыки роботает немного криво.

Слои и координаты: Управление объектами по сетке 1-10.

Логика: Система событий когда_нажата и условий если_переменая.

Как запустить:
Просто откройте index.html в любом браузере или запустите через GitHub Pages.
